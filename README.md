## 🚀 About me

I build AI agents that solve real operational problems.

- 🤖 **Prompt Engineer at Northware.** I design and build a WhatsApp conversational agent that guides applicants of two of Mexico's largest private universities from their first question to enrollment, using OpenAI and Google Gemini models, RAG, retrievers, and API and database integrations.
- 💻 **Full stack developer.** Node.js, Next.js, Python and PostgreSQL systems running in real businesses.
- 📊 **6+ years in data analysis** for port logistics and restaurant operations.
- 🎓 **Systems Engineer**, currently pursuing a **Master's in Artificial Intelligence** (Tecmilenio, IBM certifications).
